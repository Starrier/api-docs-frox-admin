## 🚀 快速开始

### 1. 环境要求

- **数据库**: MySQL 8.0+
- **字符集**: utf8mb4
- **存储引擎**: InnoDB

### 2. 数据库初始化

```bash
# 1. 创建数据库
CREATE DATABASE front_logix_admin CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 2. 执行主数据库建表语句
mysql -u username -p front_logix_admin < database-schema.sql

# 3. 执行消息中心建表语句
mysql -u username -p front_logix_admin < message-center-schema.sql
```

### 3. API 基础配置

```javascript
// API基础配置
const API_CONFIG = {
  baseURL: '/api/v1',
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json',
    Authorization: 'Bearer {token}',
  },
};
```

## 🔧 数据库设计特点

### 1. 表设计原则

- **规范化设计**: 遵循第三范式，减少数据冗余
- **索引优化**: 为常用查询字段建立索引
- **外键约束**: 保证数据完整性和一致性
- **JSON 字段**: 灵活存储复杂数据结构
- **软删除**: 重要数据支持软删除机制

### 2. 性能优化

- **分区表**: 大数据量表支持分区
- **读写分离**: 支持主从复制架构
- **缓存策略**: 热点数据缓存设计
- **批量操作**: 支持批量插入和更新

### 3. 扩展性设计

- **模块化**: 按业务模块划分表结构
- **版本控制**: 支持数据库版本迁移
- **多租户**: 支持多租户数据隔离
- **国际化**: 支持多语言数据存储
